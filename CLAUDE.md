# LLM Wiki repository guidance

## Scope

This is a content-first, source-backed wiki covering quantitative methods, software and agent workflows. Keep
repository-specific guidance here; shared agent policy lives in the global
instructions.

## Content conventions

- Write one focused concept per page using Markdown.
- Lead with an intuitive explanation, then cover mechanics, practical use, and
  limitations where relevant.
- Cite primary sources or authoritative documentation for technical claims.
- Mark observations, hypotheses, and version-sensitive behaviour explicitly.
- Use relative links between wiki pages so the content remains portable.
- Do not add generated site output, local environments, credentials, or private
  notes to the repository.

## Change conventions

- Preserve existing content and use small, reviewable changes.
- Update the relevant index or glossary entry when adding a page.
- Check links and renderability before committing documentation changes.
